# KAVIN N — Modern Futuristic Portfolio

A futuristic, high-performance personal portfolio website engineered with **semantic HTML5**, **modern CSS3**, and **vanilla JavaScript**. Inspired by Awwwards-winning design systems and the aesthetic of `jainithilportfolio.netlify.app`.

---

## 🚀 Live Demo & Preview
- Open `index.html` in any modern web browser or serve locally via `python -m http.server 8080`.

---

## 🎨 Features & Design Highlights

- **Aesthetic**: Deep obsidian (`#06070c`) and cosmic navy (`#0b1020`) cyber dark theme with electric cyan and purple accents.
- **Typography**: Paired **Orbitron** (cyberpunk headings) with **Manrope** (clean modern body).
- **Interactive Canvas**: Floating 2D ambient particle starfield.
- **Micro-Interactions**: Trailing interactive cursor, scroll progress bar, 3D card tilt, and magnetic button effects.
- **Resume Integration**: Built-in resume viewer modal with print/save as PDF support.
- **Responsive**: 100% mobile, tablet, and desktop responsive layout.
